# Проверка автоматического обновления бюджета

Текущий проект уже использует Supabase Realtime для таблиц `contributions`, `expenses`, `campaigns` и `students`, а для администратора также для заявок на доступ.

В рамках этого этапа общий realtime-канал усилен. Ошибка `CHANNEL_ERROR`, тайм-аут или закрытие канала теперь запускают переподключение всего бюджета, а не только чат-механики. При возвращении сети канал пересоздаётся и выполняется тихая загрузка свежего snapshot. При возвращении на видимую вкладку выполняется тихая синхронизация.

Добавлена резервная проверка раз в 60 секунд, но только при открытой вкладке и активной сессии. Она не показывает лишние уведомления и очищается при выходе или отключении realtime.

Финансовые расчёты, Supabase RPC, выбор ребёнка, чат, архив и визуальные стили не изменялись.

Проверки прошли:

- `node --check app.js`;
- `git diff --check`;
- `test_realtime_budget_refresh.js`;
- `test_v58_chat_realtime.js`;
- `test_chat_archive.js`.

Production пока не затрагивался.
