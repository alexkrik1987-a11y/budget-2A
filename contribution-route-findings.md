# Проверка маршрута личного взноса

Локальный preview показывает, что в нижней/основной навигации теперь отображается `Взносы класса`, а в «Живой тетради» остаётся отдельная кнопка `Мой взнос`.

Кнопка `Мой взнос` больше не вызывает `switchView("contributions")`. Она остаётся на `summary` и прокручивает страницу к существующему блоку `#contributionReminder`, где находится выбор ребёнка и персональные расчёты. Если блок пока скрыт из-за отсутствия открытых сборов или списка учеников, выводится короткое информационное уведомление.

Таблица общей вкладки также получила заголовок `Взносы класса`. Финансовая логика, localStorage выбора ребёнка, персональные остатки и данные Supabase не изменялись.

JavaScript syntax check, git diff check, realtime chat test и chat archive test прошли.
