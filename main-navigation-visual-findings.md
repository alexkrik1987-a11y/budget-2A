# Проверка главной навигации и учебного года

Локальный preview обновлённой страницы успешно показал:

- вкладка `Главная` вместо `Сводка`;
- вкладка `Мой взнос` вместо `Взносы`;
- короткая инструкция для первого входа;
- три быстрых действия в «Живой тетради»: `Мой взнос`, `Открытые сборы`, `Чат класса`;
- футер с единой пользовательской версией `V1.2`.

Новая разметка не перекрывает существующие карточки и остаётся в потоке страницы. Статическая проверка показывает, что кнопки являются настоящими button-элементами и связаны с существующими действиями приложения.

Функция `displayedSchoolYearLabel` переводит старое отображение `2025–2026` в `2026–2027` в шапке, живой тетради и карточках архива, не изменяя финансовые данные или архивные записи в базе.

Preview выполнен с пустыми данными, поэтому реальные суммы и текущий сбор в нём не отображаются. JavaScript syntax check, git diff check, realtime chat test и chat archive test прошли.
