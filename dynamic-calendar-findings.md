# Проверка динамического календаря

В локальном превью статичный emoji-календарь заменён на HTML-значок с двумя динамическими полями.

Проверка показала:

- месяц и число выводятся отдельными элементами;
- на текущей дате preview отображаются `АВГ` и `20` согласно системной дате среды проверки;
- рядом большая дата также формируется из текущей даты;
- статичная дата `17 July` больше не присутствует в разметке;
- значок не зависит от emoji-шрифта телефона и будет одинаково выглядеть на разных устройствах;
- JavaScript syntax check, realtime chat test и chat archive test прошли.

В production пока не публиковалось.
